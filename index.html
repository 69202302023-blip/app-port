ขั้นตอนง่ายๆ ในการนำพอร์ตโฟลิโอนี้ขึ้นออนไลน์

  1. บันทึกไฟล์นี้: ตั้งชื่อไฟล์ว่า index.html
  2. สมัคร/เข้าสู่ระบบ GitHub:

    กดปุ่ม "New Repository" → ตั้งชื่อ repository เช่น academic-portfolio → เลือกเป็น Public → กด Create repository

  3. อัปโหลดไฟล์ index.html:

    ในหน้า Repository ที่เพิ่งสร้าง กดคลิก "uploading an existing file" ลากไฟล์ index.html ใส่ลงไป แล้วกด Commit changes

  4. เปิดใช้งาน GitHub Pages:

    ไปที่แท็บ Settings (ด้านบน) → เมนูซ้ายเลือก Pages → ตรงส่วน Source Branch เลือกเป็น main หรือ master → กด Save

  5. เสร็จเรียบร้อย!

    รอประมาณ 1-2 นาที คุณจะได้ URL เว็บไซต์ เช่น https://yourusername.github.io/academic-portfolio/ สำหรับนำไปแนบส่งอาจารย์ได้เลย!
